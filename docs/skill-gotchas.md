# Skill gotchas (one line each: reference file, then the fact)

- references/emulator-qa.md + scripts/lua/pcsx_lib.lua: PCSX-Redux nightly 32338 (2026-11-21) `PCSX.GPU.getVRAM()` returns 2 MB; the first 1 MB is the 1024x512 VRAM, the rest 0xFFFF filler. The lib comment says 1 MB.
- references/emulator-qa.md: with default `--mash`/`--mash-hold`, Guardian Recall's dialogue never advanced (route choice and title did), while a route of `4 circle;40 -` presses did. Use press routes for dialogue, or tune `--mash-hold`.
- references/platform-ps1.md: dumpsxiso extracts mixed-mode STR files as 2336-byte sectors (subheader + data); ffmpeg's psxstr demuxer rejects them until each sector gets the 16-byte sync+header back (tools/str_frames.py). One frame sheet per disc found the only burned-in text (credits).
- references/emulator-qa.md: L.on_exec/on_read/on_write stop with "require emu.py --debugger" (exit 2); PCSX runs have no --headless flag (window already hidden).
- scripts/lua/pcsx_lib.lua: LuaJIT `<<`/`|` on PCSX.getMemPtr() bytes give signed 32-bit, so a u32 >= 0x80000000 read that way never equals the literal (warp never fired). Build u32 with `+`/`*` arithmetic.
- references/emulator-qa.md (PCSX): a game exception pauses PCSX-Redux with no UI, so vsync stops and emu.py ends in 124 (timeout) with no Lua error. `PCSX.Events.createEventListener("ExecutionFlow::Pause", ...)` + `PCSX.getRegisters().pc` names the faulting PC (work/probe_pause.lua pattern).
- scripts/emu.py: `--var ROUTE=...` is refused (driver global); name a script's own route var something else (WROUTE).
- references/emulator-qa.md (PCSX): without `--sav`, every run shares tools/pcsx/memcard1.mcd and the game writes to it; parallel runs race. Pass a fixture card per run.
- references/emulator-qa.md §Debug tool: a regen pool killed by taskkill on its emulators keeps starting new ones; kill the parent python (regen) first. Two sweeps writing the same work/qa dirs silently mixed results.
- references/emulator-qa.md §Agent playtest: play.py's default 6-frame press was dropped by this game's tactics menus about half the time; `circle*8` (held 8 frames) with --gap 30 was reliable. Menus that scroll also ignore presses closer than ~30 frames.
- scripts/lua/pcsx_lib.lua: a Lua script cannot drop the rest of a queued route; to end a run on a game condition call L.shot("final.png"), L.log("final frame N"), L.save_state(STATE_OUT), L.finish(0) itself (warp.lua `stop:X+N`). Worth an L.stop() helper in the driver.
- references/platform-ps1.md: PCSX-Redux exec breakpoints ignore the width argument (one hook per address: tools/lua/exec_range.lua); write breakpoints on the stack make a run ~100x slower (a 20-frame window took >1 h).
- references/platform-ps1.md: warp by injecting event-script bytes at the interpreter PC (warp.lua op: target) reaches scene changes a mode setter call can't; check the arg byte order of the script reader first (this game: little-endian u16).
- references/platform-ps1.md: PCSX-Redux (nightly 32338) can hang a game that waits on an XA voice line's end (here an ally's retire line on the tactics map: a status bit never clears, every button ignored); a Lua watchdog that clears the bit after N frames (tools/lua/unstick.lua) works around it. Check for this before calling a map hang a softlock.
- references/emulator-qa.md §Debug tool: to force a game over or win, clamp HP (only lower it, never pin it) every frame rather than writing 0: the defeat/victory check here runs only after a battle, and a pin would also undo the battle's write-back of 0.
- scripts/tbl.py + references/pipeline.md §Extract: one game can store the same kana two ways (scenario single-byte hiragana, EXE SJIS pairs; ー as B0 or 815B). tbl.py escapes the non-canonical form as [XX] (896 escapes here); fix = table variants with different canonical order, each record names the one that decodes it without escapes.
- references/pipeline.md §Extract: archive repacks were byte-identical only after keeping each entry's stale sector padding (UNN.PAK sub-entries, GRETC.RLZ entries): zero-padding broke identity at the first entry.
- references/pipeline.md §Extract: a lookahead regex is needed for opcode-prefixed strings (`34 05 34 00 0b name`): non-overlapping finditer ate the real op.
