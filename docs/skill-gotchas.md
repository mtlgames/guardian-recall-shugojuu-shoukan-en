# Skill gotchas (one line each: reference file, then the fact)

- references/emulator-qa.md + scripts/lua/pcsx_lib.lua: PCSX-Redux nightly 32338 (2026-11-21) `PCSX.GPU.getVRAM()` returns 2 MB; the first 1 MB is the 1024x512 VRAM, the rest 0xFFFF filler. The lib comment says 1 MB.
- references/emulator-qa.md: with default `--mash`/`--mash-hold`, Guardian Recall's dialogue never advanced (route choice and title did), while a route of `4 circle;40 -` presses did. Use press routes for dialogue, or tune `--mash-hold`.
- references/platform-ps1.md: dumpsxiso extracts mixed-mode STR files as 2336-byte sectors (subheader + data); ffmpeg's psxstr demuxer rejects them until each sector gets the 16-byte sync+header back (tools/str_frames.py). One frame sheet per disc found the only burned-in text (credits).
- references/emulator-qa.md: L.on_exec/on_read/on_write stop with "require emu.py --debugger" (exit 2); PCSX runs have no --headless flag (window already hidden).
- scripts/lua/pcsx_lib.lua: LuaJIT `<<`/`|` on PCSX.getMemPtr() bytes give signed 32-bit, so a u32 >= 0x80000000 read that way never equals the literal (warp never fired). Build u32 with `+`/`*` arithmetic.
- references/emulator-qa.md (PCSX): a game exception pauses PCSX-Redux with no UI, so vsync stops and emu.py ends in 124 (timeout) with no Lua error. `PCSX.Events.createEventListener("ExecutionFlow::Pause", ...)` + `PCSX.getRegisters().pc` names the faulting PC (work/probe_pause.lua pattern).
- scripts/emu.py: `--var ROUTE=...` is refused (driver global); name a script's own route var something else (WROUTE).
- references/emulator-qa.md (PCSX): without `--sav`, every run shares tools/pcsx/memcard1.mcd and the game writes to it; parallel runs race. Pass a fixture card per run.
- references/emulator-qa.md §Debug tool: a regen pool killed by taskkill on its emulators keeps starting new ones; kill the parent python (regen) first. Two sweeps writing the same work/qa dirs silently mixed results.
- references/emulator-qa.md §Agent playtest: play.py's default 6-frame press was dropped by this game's tactics menus about half the time; `circle*8` (held 8 frames) with --gap 30 was reliable. Menus that scroll also ignore presses closer than ~30 frames.
- scripts/lua/pcsx_lib.lua: a Lua script cannot drop the rest of a queued route; to end a run on a game condition call L.shot("final.png"), L.log("final frame N"), L.save_state(STATE_OUT), L.finish(0) itself (warp.lua `stop:X+N`). Worth an L.stop() helper in the driver.
- references/platform-ps1.md: PCSX-Redux exec breakpoints ignore the width argument (one hook per address: tools/lua/exec_range.lua); write breakpoints on the stack make a run ~100x slower (a 20-frame window took >1 h).
- references/platform-ps1.md: warp by injecting event-script bytes at the interpreter PC (warp.lua op: target) reaches scene changes a mode setter call can't; check the arg byte order of the script reader first (this game: little-endian u16).
- references/platform-ps1.md: PCSX-Redux (nightly 32338) can hang a game that waits on an XA voice line's end (here an ally's retire line on the tactics map: a status bit never clears, every button ignored); a Lua watchdog that clears the bit after N frames (tools/lua/unstick.lua) works around it. Check for this before calling a map hang a softlock.
- references/emulator-qa.md §Debug tool: to force a game over or win, clamp HP (only lower it, never pin it) every frame rather than writing 0: the defeat/victory check here runs only after a battle, and a pin would also undo the battle's write-back of 0.
- scripts/tbl.py + references/pipeline.md §Extract: one game can store the same kana two ways (scenario single-byte hiragana, EXE SJIS pairs; ー as B0 or 815B). tbl.py escapes the non-canonical form as [XX] (896 escapes here); fix = table variants with different canonical order, each record names the one that decodes it without escapes.
- references/pipeline.md §Extract: archive repacks were byte-identical only after keeping each entry's stale sector padding (UNN.PAK sub-entries, GRETC.RLZ entries): zero-padding broke identity at the first entry.
- references/pipeline.md §Extract: a lookahead regex is needed for opcode-prefixed strings (`34 05 34 00 0b name`): non-overlapping finditer ate the real op.
- references/platform-ps1.md: dumpsxiso writes the dumped tree's ABSOLUTE path into layout.xml (`directory_tree source=`). A build that copies the dump to a work dir and patches there still packs the pristine files, and the identity test can't see it. Rewrite the source attribute, and grep the built .bin for a marker string.
- references/platform-ps1.md: a game's own malloc arena can cover the "free" heap top that dumps show as zero (here base [0x800120DC]+0x800 to 0x801F7F00). Find the arena init (write watch on the descriptor's size field) and shrink it to own RAM, rather than trusting zero bytes.
- references/platform-ps1.md: cutting RAM off the malloc arena for a payload can surface unchecked mallocs: here a per-frame 2D primitive pool grows by malloc on demand and never checks for 0, so longer English text (more glyph packets) fragmented the smaller heap, the pool base became 0 and packets overwrote the kernel (crash pc 0x641C / exception vector, far from the text code). Log the pool struct per frame (tools/lua/pool2d.lua pattern) before hunting a "fixed buffer"; a stall the original disc also shows can be the same bug.
- references/platform-ps1.md: enlarging a game's own malloc'd text buffer (here battle quotes 0x2800 -> 0x4000) on top of an arena cut made that malloc return 0 on the busiest screen; the CD DMA then loaded the block to address 0 and the kernel died (pause pc 0xF8 in a B0 call, far from any text code). A write watch on 0x0-0x200 caught the DMA at a GPU-register store. Prefer static buffers in zero BSS gaps (xref-scan the EXE and every overlay for lui pairs into the gap first) and walk the heap (tools/lua/heap.lua) on the original to know the real peak.
- references/platform-ps1.md: armips "register t1 may not be available due to load delay" is a real R3000 bug (an `lbu t1` then `sh t1` stored the old t1 on hardware) that PCSX-Redux hid: the VWF looked right in the emulator. Treat armips load-delay warnings as errors; fill the slot with an independent instruction.
- references/pipeline.md §Checks: for romdiff `--writes` with an armips patch, take the emitted spans from `armips -temp <listing>` (each line = address + source; `.org`/`.headersize`/`.close` lines end a span, `.headersize` lines show the resolved value, so payload spans map back to file offsets too) and log the pre/post-armips diff runs as writes; merge adjacent spans (`.org X` then `.org X+4` make one diff run). A small runtime test: copy only the patched files into a mini tree and flip one byte per file kind.
- references/pipeline.md §Checks: an English `%` in text that is not a printf format is fine only if the engine never runs it through sprintf; check by shot (`build.py --qa ID="100% of %d"`), then lint only records whose Japanese holds conversions (same conversion letters in order).
- references/emulator-qa.md §Debug tool: to shoot the longest value of a stat-driven label (unit type, equipment), poke the unit record from a Lua probe after the map loads (tools/lua/unit_type.lua, poke.lua AT=frame) instead of hunting a save that has it; tables printed only by a leftover debug printf (look for "table[%d]" format strings) need no width work.
- references/emulator-qa.md §Debug tool: PCSX-Redux exec hooks (`emu.py --debugger`) can write registers: `PCSX.getRegisters().GPR.n.s3 = 59` inside `L.on_exec(addr, ...)` takes effect before the instruction runs. Forcing a switch case or a branch register this way reached three popups no scene reaches naturally (tools/lua/setreg.lua, HOOKS='0xADDR:reg=val;...'); poke task-state RAM every frame (poke.lua EVERY=1) when the state lives in memory instead.
- references/emulator-qa.md §Visual QA: a popup drawn for one frame or on a frame-counter blink bit is missed by --shot-every; find the frame from the probe log and shoot it with `--shots N,N+1,...`.
- references/graphics.md §Survey: a graphic with no known source: dump VRAM on that screen (scripts/lua/probes/ppudump.lua), take 8-byte rows of the tile and search every disc file raw and every decompressed stream (TX03 here); found the PS1 orbs in minutes after a size-based sweep failed. Watch for TIMs whose CLUT block is really a second pixel block (flag 8, CLUT w 64 h 216).
- references/platform-ps1.md (FMV text): redrawing text in an MDEC v2 STR (tools/staff_str.py): at qscale 1, white-on-black text pushes AC levels past the 10-bit escape range (±511) and clipping shows as grey 8x8 blotches; raise qscale until no level clips. Re-encode only macroblocks the edit touches (re-encoding decoded noise grows a frame 20%), and erase the old text with a grey opening larger than a text line (7x7 left grey cores inside dense kanji).
- references/emulator-qa.md (Visual QA): PS1 320x240 shots at sheet.py --div 2 (emu.py --sheet default) leave dialogue glyphs unreadable; visual-QA sheets need --div 1 (tools/vqa_sheets.py), ~3x the image tokens.
- references/emulator-qa.md (Visual QA): a code fix that touches a box shown in a long scene (battle, gameover) changes dozens of already-verdicted sheets through that one box; rerun those scenes on the previous build and pixel-diff frame by frame (tools/framediff.py NEW OLD): when every diff bbox is the fixed box, the old verdicts carry over with that evidence instead of a 500-tile re-read.
